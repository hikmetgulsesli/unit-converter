## Codebase Patterns

### Project Stack
- React 19 + Vite + TypeScript
- Testing: Vitest + React Testing Library
- Icons: Lucide React
- CSS: Component-scoped CSS files with CSS custom properties

### Design System
- Using DevTool/CLI Dashboard color palette (cyan primary, zinc surfaces)
- Font: Space Grotesk (heading) + DM Sans (body) - Font pair #1
- CSS variables defined in src/index.css
- Dark mode first design

### Component Patterns
- Components in src/components/
- CSS files alongside components (ComponentName.css)
- Tests in src/components/__tests__/ or alongside (ComponentName.test.tsx)
- Exports in src/components/index.ts

### Testing Patterns
- Use vitest with @testing-library/react
- Tests use render, screen, fireEvent from @testing-library/react
- Tests use vi from vitest for mocks
- Use toBeInTheDocument(), toHaveTextContent(), toHaveAttribute() matchers
- Avoid getComputedStyle checks in jsdom - use className checks instead

### CSS Patterns
- BEM naming: .component-name__element--modifier
- CSS variables for all colors, spacing, typography
- Transition only background-color, border-color, box-shadow, transform, opacity
- Reduced motion media query always included
- focus-visible for keyboard focus states

### App Layout Pattern
- App component uses semantic HTML: header, main, footer
- Flex column layout with min-height: 100vh
- Main content area uses flex: 1 to take available space
- Container max-width with auto margins for centering
- Responsive breakpoints at 640px and 1024px

### Accessibility Patterns
- Use forwardRef to pass refs to DOM elements for focus management
- ARIA live regions with aria-live="polite" for non-intrusive announcements
- sr-only utility class for screen reader only content
- Keyboard shortcuts support both Ctrl and Cmd for cross-platform compatibility
- All form inputs must have associated labels
